# Kit de ventas y documentos legales

| Documento | Para qué | Cuándo se usa |
|---|---|---|
| [checklist-diagnostico.md](checklist-diagnostico.md) | Guion, preguntas y plantilla de resumen | Antes y durante el diagnóstico de 30 minutos |
| [propuesta-comercial.md](propuesta-comercial.md) | Alcance, plazos, precio en UF y garantía | Máximo 48 horas después del diagnóstico |
| [nda.md](nda.md) | Acuerdo de confidencialidad mutuo | Si el prospecto mostrará información sensible antes de contratar |
| [contrato-servicios.md](contrato-servicios.md) | Contrato de prestación de servicios | Al aceptar la propuesta |
| [anexo-tratamiento-datos.md](anexo-tratamiento-datos.md) | Anexo de encargo de tratamiento (Ley 21.719) | Junto al contrato, si tratamos datos personales del cliente |

**Los contratos, el NDA y el anexo de datos son borradores:** hay que revisarlos con un abogado antes de usarlos con clientes. Para enviarlos, conviértelos a PDF o Google Docs y reemplaza todo lo que está entre [CORCHETES].
